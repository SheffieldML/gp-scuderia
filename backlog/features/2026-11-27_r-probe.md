## Progress Updates

### 2026-11-27
Created from the accepted CIP-0007. Started: R 4.5.2 is installed, none of the packages are.

Installed into the git-ignored `.rlib/` of the worktree: DiceKriging 1.6.1, jsonlite 2.0.0, yaml 2.3.12 (C only, no C++ needed).

Blocked: kergp and GauPro. Both depend on compiled C++ packages (nloptr, RcppArmadillo). Two toolchain faults on this machine:
- clang++ searches `CommandLineTools/usr/include/c++/v1`, which does not exist; the headers are under `SDKs/MacOSX.sdk/usr/include/c++/v1`. A user Makevars with `-isystem` fixes the compile step for most packages.
- R's Makeconf links the Fortran runtime from `/opt/homebrew/opt/gcc/...`, and Homebrew gcc is not installed, so linking fails (`library 'emutls_w' not found`).

Needs `brew install gcc` (or equivalent) before kergp and GauPro can build.
